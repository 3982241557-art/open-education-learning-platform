#  开放教育学习平台 · 后端依赖

#  这份清单是**实际用到什么就写什么**——每个包都在代码里有对应引用，

#
#  安装：
#
#      pip install -r requirements.txt

# ── Web 框架 ──────────────────────────────────────────────────
fastapi>=0.115.0

# ASGI 服务器。
#
# ``[standard]`` 额外装了 ``uvloop``（事件循环更快）与 ``httptools``
# （HTTP 解析更快）——它们在 slim 镜像里需要编译，所以 Docker 里
# 装上了 ``build-essential`` 也没关系（见 Dockerfile）。
uvicorn[standard]>=0.30.0

# 数据校验与序列化。
pydantic>=2.7.0

# ── HTTP 客户端 ───────────────────────────────────────────────
#
# 所有出站请求（模型调用、GitHub API、B 站接口、课程抓取）都用它。
# 异步版比 ``requests`` 快得多，而且能跟 FastAPI 的事件循环共用。
httpx>=0.27.0

# ── 配置文件 ──────────────────────────────────────────────────
#
# skill 库与能力包是 YAML 格式的。
PyYAML>=6.0.1

# ── 环境变量 ──────────────────────────────────────────────────
#
# 读 ``backend/.env``。
#
# 注意：``env_loader`` 里已经写了**手写解析器**作为兜底——所以这个包
# 缺失时平台依然能启动（只是会打一条警告）。但装上它更省事。
python-dotenv>=1.0.0

# ── 繁简转换 ──────────────────────────────────────────────────
#
# 繁体 → 简体的强制清洗。纯 Python 实现，无需编译。
#
# 缺失时平台自动降级到字符级对照表（``_t2s_table.py``）——转换质量会
# 差一点，但不会崩。
opencc-python-reimplemented>=0.1.7

# ── 媒体抓取 ──────────────────────────────────────────────────
#
# YouTube 频道投稿列表走 ``yt-dlp --flat-playlist``。
#
# 它以**命令行工具**的形式被调用（不是 import），所以装的是可执行
# 文件。缺失时 YouTube 线路不可用，B 站线路不受影响。
#
# 需要 ffmpeg 才能合并分离的音视频流——见 Dockerfile。
yt-dlp>=2024.8.6
