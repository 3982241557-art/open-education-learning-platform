/**
 * 证书独立预览页
 * ==============
 *
 * ``/learning/certificates/?id=<证书 id>``
 *
 * 为什么用**查询参数**而不是路径参数
 * --------------------------------
 *
 * 静态导出（GitHub Pages）的一个硬约束：**构建期没生成的路径不存在**。
 *
 * 而证书 id 是**运行时**才有的——用户在浏览器里完成课程才颁发。
 * 构建期不可能知道会有哪些 id，所以 ``/certificates/<id>`` 这种路径
 * 在静态站点上**永远 404**。
 *
 * 查询参数就绕开了这个问题：
 *
 * * ``/learning/certificates/`` 这个路径是**静态**的，构建期就存在；
 * * id 放在 ``?id=...`` 里，页面在浏览器里读；
 * * 分享链接、打印、验证都照常工作。
 *
 * 代价
 * ----
 *
 * URL 没那么「好看」（``?id=xxx`` vs ``/xxx``）。但换来的是**在纯静态
 * 托管上真的能用**——这比好看重要得多。
 *
 * 旧链接兼容
 * ---------
 *
 * 之前分享出去的 ``/learning/certificates/<id>`` 链接在静态站点上会
 * 走 404 回退——由 ``GhPagesRedirect`` 把它改写成带 ``?id=`` 的形式。
 */

/** 证书查询参数的键。 */
export const CERTIFICATE_QUERY_KEY = "id";
